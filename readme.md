## 1. 数据集内容

## 2. 模型预测
### 2.1 模型说明
本研究在 LORO 划分（151 训练 / 73 测试小区）下，系统比较了4个传统的模型与2个深度模型在面对62个特征×11个时相下的产量预测情况，各个模型说明如下：
1. 均值基线不作任何学习，直接输出训练集产量均值，用于量化"完全不利用特征"时的误差水平；
1. 岭回归通过 L2 惩罚稳定共线高维数据的求解，保留全部 682 个变量；
2. LASSO 回归利用 L1 惩罚的稀疏性自动完成特征选择，可剔除冗余的相邻时相观测；
3. XGBoost 采用梯度提升决策树集成，能够拟合非线性关系与特征交互，且对共线性不敏感。
4. CNN1D 采用局部卷积核在时间维滑动，通过两层 kernel=3 的 Conv1d 逐层扩展感受野至 ±2 个时相，模拟相邻观测之间的生长速率变化；卷积核权重在全部时相位置共享，保证了参数效率（33,089）。末端使用全局平均池化，避免因时相数固定而限制模型部署。
5. Transformer 则通过自注意力机制建立任意时相之间的直接连接。在特征投影后引入可学习位置编码以注入时序信息，随后经 2 层、每层 4 头的 TransformerEncoder 完成全局信息融合。相较正弦位置编码，可学习编码更适合本数据非等间隔采样（6–30 天）的特性。末端采用可学习注意力池化替代平均池化，在提升表达能力的同时为模型提供了时相权重的可解释出口。

### 2.2 产量预测

结果可以看出CNN1D 取得最优性能（R² = 0.935，RMSE = 0.853 t/ha，NRMSE = 8.49%），显著优于其他所有模型

其次，非线性优于线性 XGBoost（R²=0.870）较 Lasso（R²=0.844）提升 0.026，较 Ridge（R²=0.788）提升 0.082。Lasso 的 L1 正则自动剔除了冗余特征，效果优于岭回归的 L2 正则，说明 682 个特征中确实存在大量共线冗余。

而 Transformer 反而低于 XGBoost（0.850 vs 0.870）。这说明深度模型并非必然优于树模型，其优势依赖于架构与数据规模的匹配

### 2.3 时相与特征权重

为揭示模型的决策依据，本研究采用注意力池化权重与遮挡法（occlusion）两种方法进行可解释性分析。

方法选择上需说明一点：本研究中 CNN1D 精度最高（R²=0.935），但其注意力权重与遮挡法所测真实贡献的秩相关仅 ρ=0.26（p=0.43，不显著），即权重排序与实际影响基本无关，不具备解释价值。相较之下，Transformer（R²=0.850）的注意力权重与遮挡法结果的秩相关达 ρ=0.61（p=0.047，显著），能够可靠反映各时相的真实影响。

这一差异源于架构本身：Transformer 的自注意力机制使各时相的表征保持相对独立，注意力池化权重直接决定各期信息进入最终预测的比例；而 CNN 的卷积操作在时间维局部混叠相邻时相，后续权重只能基于已混合的特征打分。因此，本研究以精度更高的 CNN1D 作为预测模型，以权重经交叉验证的 Transformer 作为可解释性分析对象。

结果表明，模型赋予分蘖中期（t1，权重 0.2325）、孕穗初期（t5，0.1939）最高权重，这与水稻产量形成的关键窗口（分蘖决定穗数、孕穗决定穗粒数）高度吻合。而孕穗至抽穗期（t6-t8）权重仅 0.017–0.019，反映该阶段冠层完全闭合、光谱饱和、信息冗余。

此外，采用遮挡法（occlusion）对 11 个时相 × 62 个特征共 682 个时相-特征组合逐一施加扰动，以扰动前后预测产量的平均绝对变化量作为该组合的重要性度量。分析得到四项主要发现。

1. 拔节末期（t4）的 CVI 构成全局最强信号，其重要性达 0.123 t/ha，为全部 682 个组合的最高值，是次高组合（t3 的 CVI，0.074 t/ha）的 1.66 倍。CVI 对高叶绿素含量敏感，而拔节期正是叶绿素浓度峰值与穗粒数决定的关键窗口，二者高度吻合。

2. 孕穗初期（t5）由气象因子主导：该期重要性最高的特征为 heat35_7d（前 7 日最高温超过 35 ℃ 的天数，0.057 t/ha），而非任何光谱特征。抽穗期（t8）与灌浆中期（t10）同样呈现气象主导格局。这说明在冠层完全闭合后，光谱信息饱和，热量与温度条件成为产量差异的主要来源。

3. 孕穗至抽穗期（t6–t8）存在明显的信息真空带：三期全部特征的重要性之和仅占 11 期总和的 12.6%，其中 t7 的单期总和仅 0.214 t/ha，不足拔节末期（1.051 t/ha）的 21%。该阶段冠层完全闭合、叶面积指数饱和，多光谱指数区分度显著下降，模型自动降低了这些时相的依赖程度。

## 3. 讨论
最后需要说明的是，深度模型在 LORO 下实现反超的关键在于气象模态的时序利用。消融实验显示，加入气象特征后 CNN1D 的 R² 从 0.838 提升至 0.935，而 XGBoost 仅提升 0.0015。其原因在于气象特征是 11 期时间序列，与影像时序在时间轴上对齐。卷积层能够在时间维同时处理光谱与气象，学到"某期高温/干旱与冠层生长的交互"；而树模型将全部特征扁平化，丢失了跨模态的时间对应关系，因此气象贡献被淹没在 539 个影像特征中。这说明：模态融合的价值不在于"特征更多"，而在于"能否保持模态间的时间对齐"。
